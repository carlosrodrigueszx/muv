# MUV
MUV é uma plataforma web desenvolvida para conectar clientes a prestadores de serviços de frete, como motoristas autônomos e empresas de transporte. O sistema permite divulgar, solicitar, contratar e gerenciar serviços de transporte de pessoas e encomendas, facilitando a comunicação entre as partes e o acompanhamento dos serviços contratados.
